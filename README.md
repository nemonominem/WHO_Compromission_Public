## About

This investigation documents how Chinese access control, Western narrative management, conflicted scientific actors, and WHO's own institutional weakness interacted to produce the WHO's failure on COVID-19 origins.

Both origin hypotheses remain live among specialists. The investigation focuses on the institutional failure, not on the origin question per se.
